- Source review found all contact/directions/booking clicks emitted `generate_lead`. These now emit `contact_click`, `directions_click`, `booking_click` or `bookshop_click`. The Shopify handoff emits `checkout_click`, replacing the old `begin_checkout` event. Neither proves a completed booking, checkout, sale or payment. Custom link events omit query strings, fragments and contact details.
- Kept GA4 ID `G-Y7R5K9NMW0`. Kept Shopify `/cart/variant:quantity` links, `attributes[Storefront]=Namaste Great Finds`, `attributes[Site]=namastegreatfinds.com`, the existing note and `ref`. Added fixed referral UTM tags to bookshop links and checkout handoffs: `utm_source=namastegreatfinds.com`, `utm_medium=referral`, `utm_campaign=namaste_storefront`; `utm_content` identifies `booking`, `product`, `bookshop` or `checkout`. Incoming visitor query strings are not copied.
- Product options now retain their own snapshot prices while a live lookup is pending or unavailable. A failed lookup no longer claims current stock; removed live options cannot be added. Live price, availability and quantity limits still come from the existing public Shopify product endpoint.
- Compare-at prices now belong to the same variant as the displayed price. The default product option matches the lowest available price shown in listings. All original variant IDs, prices and availability values are preserved; options over $60 are retained and described as separately priced.
- Added product-detail links to the authoritative bookshop listings. Removed unconditional same-day/two-hour pickup promises. Pickup requires the checkout option and ready email.
- Removed duplicate Open Graph metadata and invented product manufacturer branding. Empty brand/collection pages and the 404/cart pages are excluded from indexing/sitemaps. Known gift/aisle routes still exist when a collection becomes empty, preventing links from breaking after daily stock changes.

No workaround around the network policy was attempted.
- GSC Wizard `list_ga4_properties` returned `connected: false` because Analytics scope is absent. No visitor, customer, transaction or revenue counts can be claimed. Authorized GA4 reporting access is needed to check receipt of the unchanged measurement ID and new events.
- GSC Wizard exposes only `sc-domain:namastebookshop.com`; Great Finds indexing, sitemap submission and search performance are unverified. Add/verify the correct Great Finds property with existing authorized ownership before submitting its sitemap. No verification credential was created.
- Paid orders must be reconciled in Shopify using the storefront/site order attributes and actual payment state; deduplicate by order/transaction ID and account for cancellations/refunds. Basket values on `checkout_click` are intent, not revenue. [Shopify documents the preserved permalink attributes and referral code](https://shopify.dev/docs/apps/build/checkout/create-cart-permalinks); GA4 [purchase events](https://developers.google.com/analytics/devguides/collection/ga4/reference/events#purchase) belong to confirmed transactions.
- Booking clicks hand off to Namaste Bookshop; they do not prove a Square booking or payment. Provider-side booking/payment records and an approved source mapping are needed to attribute completed bookings. This review did not add such an integration.
- No deployment of these changes has been attempted. The review branch can be merged after live QA/access is available and production release is authorized. Merging to `main` triggers the existing Pages deployment workflow.
